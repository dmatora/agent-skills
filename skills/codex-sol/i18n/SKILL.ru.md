# Воркфлоу консультаций с глубоким мыслителем Codex и Протокол приземления (`codex-sol`)

Этот навык соединяет быструю рабочую модель в IDE (Antigravity / Claude Code / Cursor) с флагманскими рассуждающими моделями OpenAI через локальный Codex CLI (`ask-codex`).

## Разделение ролей

- **Флагманская модель Codex («Глубокий мыслитель»):**
  - Отвечает за сложную математику, проектирование алгоритмов, доказательство инвариантов, криптографию и поиск неочевидных краевых случаев.
  - **Слабость:** склонна к гиперперестраховке, академическому многословию и построению «сферических коней в вакууме» в отрыве от реалий проекта.
- **Основной агент («Партнёр по приземлению и исполнитель»):**
  - Формулирует чёткие запросы с реальным контекстом проекта, чтобы не дать мыслителю галлюцинировать.
  - Перехватывает ответ, отсекает лишние абстракции и перестраховку.
  - Переводит идею на человеческий язык и приземляет её в идиоматичный код проекта с проверкой тестами.

---

## Когда вызывать Codex

1. Проектирование сложных алгоритмов, математических кривых, токеномики или нетривиальных стейт-машин.
2. Поиск узких мест, состояний гонки (race conditions) и векторов атак в критических узлах.
3. Архитектурные развилки с неочевидными компромиссами.
4. Прямой запрос пользователя подключить Codex / Terra / Sol или проверить/переключить модель.

**НЕ использовать** для рутинного кода, простого рефакторинга и бытовых вопросов.

---

## Вызов и переключение моделей

### 1. Запрос к текущей активной модели (`ask-codex`)
Никогда не хардкодьте версии моделей в промптах. Вызывайте `ask-codex` (алиасы: `ask-sol`, `ask-terra`) — утилита сама использует выбранную пользователем модель:

```bash
ask-codex "Подробный архитектурный вопрос"

# Или через stdin для длинного контекста:
ask-codex << 'EOF'
Проверь инвариант для этой стейт-машины:
[контекст и код]
EOF
```

### 2. Просмотр списка и переключение моделей
OpenAI регулярно обновляет список доступных моделей в `~/.codex/models_cache.json`. Если пользователь просит посмотреть доступные модели или переключиться:

```bash
# Вывести живой список всех моделей из кэша Codex и показать текущую [ACTIVE]:
ask-codex --models

# Переключить модель по умолчанию (поддерживается поиск по подстроке: terra, sol, astra):
ask-codex --set terra

# Разовый запрос к конкретной модели без изменения дефолта:
ask-codex -m sol "Глубокая проверка краевого случая"
```

## Протокол приземления (Обязательный фильтр из 5 шагов)

Получив ответ от Codex, агент обязан пройти 5 шагов перед ответом пользователю или написанием кода:

1. **Выделить зерно:** найти главную алгоритмическую или архитектурную мысль.
2. **Отсечь «сферических коней»:** выбросить лишние оговорки, нереалистичные гипотезы и избыточные слои абстракции.
3. **Привязать к проекту:** адаптировать решение под существующие типы, библиотеки и конвенции репозитория.
4. **Перевести на человеческий язык:** изложить суть пользователю коротко, ясно и по делу.
5. **Воплотить и проверить:** написать код и прогнать тесты.
