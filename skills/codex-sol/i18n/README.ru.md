# Codex Grounding Bridge (`codex-sol`) — Как подружить быструю IDE с глубоким мыслителем и отсечь «сферических коней»

## Зачем это нужно (Две подписки и сломанный воркфлоу)

Почти у каждого опытного разработчика сейчас открыты два инструмента:
1. **Быстрый агент в IDE** (Antigravity, Claude Code, Cursor), который отлично ориентируется в проекте, правит файлы и гоняет тесты.
2. **Десктопный ChatGPT (Plus / Pro)**, где живут самые тяжёлые рассуждающие модели OpenAI (`gpt-6.1-terra`, `gpt-6.1-sol`, `gpt-6-astra`), способные расколоть сложную математику, криптографию или неочевидный инвариант стейт-машины.

Но на практике работа с ними упирается в три боли:
* **Ручной копипаст между окнами:** приходится руками таскать куски кода из IDE в окно ChatGPT и обратно.
* **Синдром «сферического коня в вакууме»:** старшие рассуждающие модели невероятно умны, но обожают перестраховываться, городить трёхэтажные академические абстракции на пустом месте и изъясняться тяжёлым птичьим языком. Если переносить их советы в код напрямую — проект превращается в монстра.
* **Бесконечная чехарда моделей:** вчера флагманом был `6.1-sol`, сегодня вышел `6.1-terra` (почти такой же умный, но в 2 раза экономичнее по лимитам), а через месяц выйдет новая версия. Переписывать промпты и скрипты под каждую новую модель — безумие.

## Что делает этот навык

1. **Вскрывает спрятанный нативный CLI внутри `ChatGPT.app` (без отдельной оплаты API):**
   Мало кто знает, что внутри обычного десктопного приложения `/Applications/ChatGPT.app` на macOS лежит полноценный нативный бинарник `CodexCLI.app`, который работает через вашу уже авторизованную сессию. Утилита `ask-codex` даёт вашему основному агенту прямой неинтерактивный мост к этим моделям без лишнего консольного мусора.
2. **Включает «Протокол приземления» (The Grounding Protocol):**
   Ваш основной агент (Antigravity / Claude) выступает в роли прагматичного техлида-переводчика:
   * Сам собирает сжатый контекст из кода и задаёт точный вопрос глубокой модели.
   * Забирает ответ и **выбрасывает из него академическую воду и «сферических коней»**.
   * Приземляет чистую алгоритмическую суть на реальные типы вашего проекта, пишет код, проверяет тестами и объясняет решение нормальным человеческим языком.
3. **Мгновенный переключатель моделей (`ask-codex --models` / `--set`):**
   Скрипт сам читает живой список доступных моделей из `~/.codex/models_cache.json`. В текстах скилла и системных правилах версии моделей не зашиты вообще — переключить дефолтную модель можно одной короткой командой или просто попросив агента в чате.

## Примеры использования

```bash
# 1. Посмотреть живой список моделей, доступных в вашем аккаунте Codex прямо сейчас:
ask-codex --models

# 2. Переключить основную модель по части имени (fuzzy match):
ask-codex --set terra

# 3. Задать вопрос активной модели напрямую (или поручить это агенту):
ask-codex "Проверь инвариант сохранения баланса при частичной ликвидации"

# 4. Разово вызвать самую тяжёлую модель без смены дефолта:
ask-codex -m sol "Найди гонки данных в этом конечном автомате"
```
