# Ask Codex

Небольшой мост для консультаций с Codex CLI из другого агента. Скилл помогает передать контекст проекта и проверить ответ перед применением.

Установка описана в [корне репозитория](../../../i18n/README.ru.md). Codex CLI должен быть установлен и авторизован. На macOS утилита сначала ищет бинарник внутри ChatGPT.app, затем ищет `codex` в `PATH`. Доступные модели и способ авторизации зависят от настройки Codex.

## Готовые команды

Посмотреть модели в локальном кэше и текущий выбор:

```bash
ask-codex --models
ask-codex --current
```

Выбрать Terra для следующих запросов:

```bash
ask-codex --set gpt-6.1-terra
ask-codex --current
```

Или выбрать Sol:

```bash
ask-codex --set gpt-6.1-sol
ask-codex --current
```

Находясь в директории проекта, попросить выбранную модель его проверить:

```bash
ask-codex "Посмотри этот проект и назови три самые важные проблемы. Файлы не изменяй."
```

Вызвать Sol для одного запроса, не меняя сохранённую модель:

```bash
ask-codex -m gpt-6.1-sol "Посмотри этот проект и назови три самые важные проблемы. Файлы не изменяй."
```

Имена моделей приведены для примера: если у вас другие модели, укажите полное имя из вывода `ask-codex --models`.

Если модель не выбрана явно, используется настройка Codex. Команда `--set` сохраняет выбор в `~/.codex/active_partner_model`; переменная `ASK_CODEX_MODEL` имеет приоритет. `CODEX_HOME` меняет директорию кэша и файла выбора. Часть имени должна соответствовать одной модели в кэше. Если кэша нет, имя передаётся как есть. Кэш может устареть и не гарантирует доступ к модели.

Запрос запускается в режиме чтения, без сохранения сессии Codex. Ответ нужно проверять с учётом проекта перед применением.
