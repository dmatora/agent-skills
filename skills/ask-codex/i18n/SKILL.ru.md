# Консультация с Codex

Используйте `ask-codex`, когда пользователь просит мнение Codex или независимый взгляд поможет разобраться в сложной задаче. Передайте нужный код, ограничения проекта и конкретный вопрос. Не включайте лишние конфиденциальные данные.

```bash
ask-codex "Вопрос и необходимый контекст"
ask-codex < prompt.txt
```

Оцените ответ с учётом проекта и запроса пользователя. Проверяйте предположения и возможные риски, объясняйте неопределённость. Меняйте код и запускайте проверки, когда этого требует задача пользователя.
